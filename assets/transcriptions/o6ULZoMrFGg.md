Tout d'abord, voyons ce qu'est JSON. JSON, ça veut dire *JavaScript Object Notation*. C'est une sorte de format léger qui permet l'échange de données entre le serveur et vous-même. C'est basé sur du code JavaScript, donc ça tombe bien : si vous connaissez un peu de JavaScript, le JSON ne devrait pas être difficile à comprendre. Il est utilisable avec tous les langages de programmation modernes, c'est-à-dire PHP, Ruby, JavaScript, etc. De plus, il est facile à lire et à écrire, ce qui est cool. Vous l'aurez compris : JSON est très pratique pour sauvegarder nos données.

De plus, JSON utilise plusieurs types de données. Nous aurons les nombres, entiers ou décimaux ; les chaînes de caractères ; les booléens, `true` ou `false` ; les *arrays* ; les objets ; et aussi la valeur `null`, qui est une valeur vide. Dans JSON, vous pouvez utiliser tous les types de données nommés ci-dessus, et rien d'autre.

En ce qui concerne la syntaxe de JSON, c'est très simple. Étant donné que c'est en quelque sorte un objet JavaScript, il va débuter avec des accolades, puis à l'intérieur, nous aurons nos données. Et vous avez ici un exemple dans un fichier JavaScript, à droite : vous avez une variable avec un objet, et vous avez ici les données JSON. Vous pouvez voir qu'il y a quelques changements par rapport à un objet JavaScript basique.

Nous allons justement voir les quelques règles à suivre lorsque vous écrivez du JSON, que ce soit à l'intérieur d'un fichier JavaScript ou dans un fichier JSON. Il faut toujours utiliser une paire clé-valeur : `"clé": "valeur"`, donc `"name": "Alex"`. Et vous pouvez voir ici qu'on met toujours des guillemets autour de la clé et de la valeur. De plus, vous ne pouvez utiliser que les types de données que nous avons vus précédemment : nombres, booléens, etc. Et enfin, dans le cas d'un fichier JSON, l'extension doit obligatoirement être `.json`. Mis à part ces petites règles, un fichier JSON s'écrit plus ou moins comme un objet JavaScript.
